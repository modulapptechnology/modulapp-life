# @life/web

App web de ModulApp Life: React, TypeScript, Vite y React Router.

```powershell
npm run web                          # desde life-frontend, en http://localhost:5173
npm run build -w @life/web           # genera apps/web/dist
```

La estructura del monorepo y los comandos de todas las apps están en el [README de life-frontend](../../README.md).
